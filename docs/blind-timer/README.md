# KOP ブラインドタイマー HTML テンプレート

ポーカータイマー（kHold'em 風レイアウト）の画面を、タイマーアプリの HTML テンプレート機能で
再現するためのテンプレートです。

| ファイル | 用途 |
|---|---|
| `kop-blind-timer.html` | **本体**。中身をそのままタイマーアプリの HTML 設定欄に貼り付けます |
| `preview.html` | 確認用。ブラウザで開くとサンプル値で表示されます（Tailwind CSS 同梱・オフラインで動作） |

`preview.html` はウィンドウを 16:9 にするか F11 で全画面にして確認してください
（実機と同じく「表示領域いっぱい」に描画されるため）。

---

## 画面構成

```
┌──────────────────────────────────────────────────────────┐
│ [LOGO]            Knight of Poker            ← 固定テキスト │
│                    {{sessionName}}                        │
├───────────┬──────────────────────────┬───────────────────┤
│   PRIZE   │   LEVEL {{currentLevel}} │   REGISTRATION    │
│ 1. …      │                          │  {{regClose…}}    │
│ 2. …      │      {{remainingTime}}   │  Time left        │
│ 3. …      │                          │                   │
│ 4. …      │                          │  NEXT BREAK IN    │
│ 5. …      │   BLINDS (BB ANTE)       │  AVERAGE STACK    │
│  PLAYERS  │   SB | BB (ANTE)         │  TOTAL CHIPS      │
│ {{player…}}│  NEXT LEVEL - …         │                   │
├───────────┴──────────────────────────┴───────────────────┤
│              {{announcementBody}}（静止1行）              │
└──────────────────────────────────────────────────────────┘
```

## プレースホルダー対応

| 表示 | プレースホルダー |
|---|---|
| イベント名（ヘッダー下段） | `{{sessionName}}` |
| レベル | `{{currentLevel}}` |
| 残り時間 | `{{remainingTime}}` |
| ブラインド | `{{smallBlind}}` / `{{bigBlind}}` / `{{ante}}` |
| 次レベルのブラインド | `{{nextSmallBlind}}` / `{{nextBigBlind}}` / `{{nextAnte}}` |
| プレイヤー数 | `{{playerCount}}` |
| レジクローズ残り | `{{regCloseCountdown}}` |
| 次のブレークまで | `{{nextBreakTime}}` |
| アベレージスタック | `{{averageStack}}` |
| 総チップ | `{{totalChips}}` |
| アナウンス | `{{announcementBody}}` |

未使用：`{{nextBlindLabel}}` `{{elapsedTime}}` `{{regStatus}}` `{{totalEntries}}`

## 運用時に書き換える箇所

### 1. PRIZE（毎イベント）

`<!-- ▼▼▼ PRIZE：ここだけ書き換えてください ▼▼▼ -->` のブロック。
1行1件です。**行を足す／削るだけ**で件数を変えられます。

```html
<span class="text-right">1.</span><span class="text-left">Main Seat</span>
<span class="text-right">2.</span><span class="text-left">¥50,000</span>
```

> タイマー側にプライズ用のプレースホルダーが無いため、ここは手動更新です。
> 設定画面にプライズ入力欄が見つかった場合は、そのプレースホルダーに差し替えられます。

### 2. ロゴ

`<img src="…">` の `src` を差し替えるだけです。
高さ `h-[8vh]` ・最大幅 `max-w-[7.5vw]` で自動調整されるため、縦横比は問いません。

### 3. シリーズ名

ヘッダー上段の `Knight of Poker` を直接編集します。

## 主な仕様・制約

- **対応アスペクト比：16:9 および 16:10**。1280×720 〜 3840×2160 で表示崩れがないことを確認済み。
  4:3 は横幅が足りず崩れます。
- 文字サイズは `vh`（表示領域の高さ基準）指定のため、解像度が変わっても比率は一定です。
- フォントは `Arial` を inline style で明示。日本語は `Hiragino Kaku Gothic ProN` / `Noto Sans JP` に
  フォールバックします。
- 数値の桁区切りはタイマーアプリが返す文字列をそのまま表示します（HTML 側では加工しません）。
- **次レベルの番号は表示できません**（該当プレースホルダーが存在しないため `NEXT LEVEL - …` 表記）。
- **アベレージスタックの BB 換算は表示できません**（実数のみ）。
- テロップは横スクロールなしの静止1行です。長すぎる場合は末尾が `…` で省略されます。
- ブラインド欄は 6 桁（例：`250,000 | 500,000 (500,000)`）まで1行に収まることを確認済み。

## 確認済みのケース

| ケース | 結果 |
|---|---|
| 1280×720 / 1920×1080 / 3840×2160（16:9） | OK |
| 1680×1050 / 1920×1200（16:10） | OK |
| 100 文字級の長いイベント名 | OK（2行に折り返し） |
| 6 桁ブラインド・7 桁総チップ | OK |
| アナウンス未設定 | OK |
