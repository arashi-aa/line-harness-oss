# KOP ブラインドタイマー HTML テンプレート

ポーカータイマー（kHold'em 風レイアウト）の画面を、タイマーアプリの HTML テンプレート機能で
再現するためのテンプレートです。

| ファイル | 用途 |
|---|---|
| `kop-blind-timer.html` | **本体**。中身をそのままタイマーアプリの HTML 設定欄に貼り付けます |
| `preview.html` | 確認用。ブラウザで開くとサンプル値で表示されます（Tailwind CSS 同梱・オフラインで動作） |

`preview.html` は実機と同じ 1920×1080 で描画し、ウィンドウサイズに合わせて自動縮小します。
そのまま開くだけで確認できます（外部CSS・CDN不要）。

## 運用時に書き換える箇所

### 1. PRIZE（毎イベント）

`<!-- ▼▼▼ PRIZE：ここだけ書き換えてください ▼▼▼ -->` のブロック。
1行1件です。**行を足す／削るだけ**で件数を変えられます。

```html
<span class="text-right">1.</span><span class="text-left">Main Seat</span>
<span class="text-right">2.</span><span class="text-left">¥50,000</span>
```

> **表示できる件数の上限**：イベント名が1行なら **10件**、2行に折り返す場合は **9件** まで。
> 超えた分は PLAYERS に重ならず切り取られます。
>
> タイマー側にプライズ用のプレースホルダーが無いため、ここは手動更新です。
> 設定画面にプライズ入力欄が見つかった場合は、そのプレースホルダーに差し替えられます。

### 2. ロゴ

`<img src="…">` の `src` を差し替えるだけです。
高さ 150px・最大幅 170px（`<style>` 内の `.kop-logo`）で自動調整されるため、縦横比は問いません。
ヘッダー帯の中で縦中央に配置されます。

### 3. シリーズ名

ヘッダー上段の `Knight of Poker` を直接編集します。

## 実装方式（重要）

**このタイマーアプリの Tailwind は、テンプレートを JIT で走査していません。**
アプリ側のソース（＝デフォルトテンプレート）に登場する任意値クラスだけが CSS に含まれ、
新しく書いた `[...]` は**すべて捨てられます**。切り分けテストの結果は以下のとおりです。

| 手段 | 可否 |
|---|---|
| `<style>` タグ | ✅ 効く |
| inline `style` 属性 | ✅ 効く |
| 標準クラス（`flex` `text-4xl` `bg-purple-600` など） | ✅ 効く |
| **任意値クラス（`text-[4vh]` `bg-[#16359f]` など）** | ❌ **効かない** |

そのため本テンプレートは、

- **スタイルを先頭の `<style>` ブロックに自前の CSS（`kop-` 接頭辞）で定義**
- **単位は 1920×1080 基準の `px` 固定**（アプリのプレビューが CSS 縮小表示のため、
  `vh` が何を指すか確定できない。`px` なら縮小の影響を受けない）
- `.kop-root *` で margin/padding/font-weight を自前リセット（Tailwind preflight の有無に非依存）
- 骨格には `w-[20%]` `w-[55%]` `w-[25%]` など**デフォルトテンプレートに実在する**クラスも併記
  （万一 `<style>` が除去されても3カラム構造だけは残る保険）

という構成になっています。**新しく任意値クラスを足しても効きません。**
調整する場合は `<style>` ブロック内の CSS を編集してください。

> 使える任意値クラスは次の12個のみです：
> `w-[20%]` `w-[55%]` `w-[25%]` `h-[30%]` `h-[70%]` `max-w-[70%]`
> `text-[12rem]` `text-[10rem]` `text-[6.5rem]` `text-[5.5rem]` `bg-[#0a1628]` `bg-yellow-500/20`

## 主な仕様・制約

- **描画面は 1920×1080 固定**（アプリの仕様）。全サイズを px で指定しています。
- フォントは `Arial`。日本語は `Hiragino Kaku Gothic ProN` / `Noto Sans JP` / `Yu Gothic` に
  フォールバックします。
- 数値の桁区切りはタイマーアプリが返す文字列をそのまま表示します（HTML 側では加工しません）。
- **次レベルの番号は表示できません**（該当プレースホルダーが存在しないため `NEXT LEVEL - …` 表記）。
- **アベレージスタックの BB 換算は表示できません**（実数のみ）。
- テロップは横スクロールなしの静止1行です。長すぎる場合は末尾が `…` で省略されます。
  （`<style>` が使えるため、必要になれば `@keyframes` による横スクロールも実装可能です）
- ブラインド欄は 6 桁（例：`250,000 | 500,000 (500,000)`）まで1行に収まることを確認済み。

## 確認済みのケース

1920×1080 で、**Tailwind あり／なしの両方**で検証済み（`<style>` だけで成立します）。

| ケース | 結果 |
|---|---|
| 標準表示 | OK |
| 100 文字級の長いイベント名 | OK（2行に折り返し） |
| 6 桁ブラインド・8 桁総チップ | OK |
| アナウンス未設定 | OK |
| PRIZE 3件 / 10件 | OK |
| 2行に折り返すイベント名 + PRIZE 9件 | OK |
| 長い賞品名（`¥50,000 + Main Seat`） | OK |
